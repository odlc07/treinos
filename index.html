Sincronizar entre aparelhos

Gerar um token aqui — já vem com o escopo certo marcado. Escolha validade longa e copie o valor (só aparece uma vez).
No primeiro aparelho, deixe vazio e clique em Criar. Nos outros, cole o mesmo ID. Use um gist separado do da Frequência.
O token fica salvo só neste navegador e nunca sai daqui a não ser para a API do GitHub.

Backup

Vale mesmo com a sincronização ligada. Importar substitui os dados atuais; a sincronização, ao contrário, funde.
